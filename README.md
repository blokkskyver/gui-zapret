# gui-zapret


## Навайбкодил GUI для всех рукожопиков, которым тяжело с этими запретками, чистейший отборный вайбкод, в проект зашит оригинальный репозиторий flowseal, это всего лишь графическая оболочка!

Windows GUI на Go + Wails v2 для локальной сборки [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Независимый проект, не официальный GUI Flowseal. Компактный интерфейс в стиле demoscene/keygen, без npm и внешних ресурсов интерфейса.

## Запуск и сборка

Требуются Windows 10/11, Go 1.25+ для сборки и Microsoft Edge WebView2 Runtime для запуска.

```powershell
./build.ps1
./build/bin/gui-zapret.exe
```

Сборка использует Wails v2.11.0 и Go build с тегами `desktop,production`. При необходимости Wails CLI: `go run github.com/wailsapp/wails/v2/cmd/wails@v2.11.0 build` (может потребовать дополнительные зависимости CLI). Документация: https://v2.wails.io/docs/.

По умолчанию приложение использует системную папку «Документы» (`Documents\zapret`), учитывая её перенос Windows. Сначала проверяет сохранённую папку и готовую сборку рядом с EXE. Если Flowseal не найден, предлагает скачать его или выбрать папку. Кнопкой «Выбрать папку» укажите распакованную сборку с `service.bat`, `bin`, `lists`, `utils`. В EXE не входят winws/WinDivert. Готовую сборку Flowseal можно выбрать на диске или скачать из официальных релизов кнопкой «Скачать».

## Возможности

- Статус службы через Windows Service API; текущая установленная стратегия и команда.
- Установка/обновление службы `zapret`, автоматический запуск при загрузке Windows, запуск, остановка и удаление. Применение стратегии останавливает текущую службу, обновляет параметры и запускает её. При ошибке запуска служба остаётся установленной, подробности отображаются в журнале.
- UAC по кнопке «Повысить права»: GUI перезапускается с выбранной папкой. Просмотр состояния не требует повышения прав. Закрытие GUI не останавливает службу.
- Чтение `general*.bat` как параметров winws без исполнения batch-кода. Неподдерживаемые переменные и операторы отклоняются. Произвольные BAT-скрипты не поддерживаются.
- Game Filter: выключен / TCP / UDP / TCP+UDP, диапазоны портов, совместимый `utils/game_filter.enabled`. После изменения нужно применить стратегию повторно.
- Флаг проверки обновлений для штатных BAT-запусков Flowseal. GUI самостоятельно обновления не загружает.
- IPSet, hosts, замена фейков, диагностика и тестирование доступны через кнопку открытия штатного `service.bat` и соответствующий номер меню. Эти функции пока не перенесены в собственные формы GUI.
- Папка пользовательских списков и журнал операций. Настройки GUI и `gui.log`: `%APPDATA%\gui-zapret`. Журнал содержит операции GUI, не stdout службы winws.

Удаление из GUI удаляет только службу `zapret`; общие драйверные службы WinDivert не удаляются. Для штатной полной очистки используйте пункт 2 меню Flowseal. GUI не завершает отдельно запущенные процессы winws и не изменяет TCP timestamps; такие настройки доступны через штатные инструменты.

## Проверка

```powershell
$env:FLOWSEAL_TEST_ROOT = Join-Path $env:USERPROFILE 'Desktop\zapret'
go test ./... -v
go vet ./...
```

Тесты проверяют разбор параметров, пути с пробелами, недопустимые операторы и диапазоны портов. При заданном `FLOWSEAL_TEST_ROOT` проверяют все стратегии в четырёх режимах и наличие файлов, на которые они ссылаются. Тесты не устанавливают и не запускают службу. Реальные операции со службой требуют отдельной проверки с правами администратора.

## Релизы, редактор и тест одной стратегии

Выпадающий список загружает до 50 релизов GitHub Flowseal с готовым ZIP. «Скачать» без выбора версии загружает последний стабильный релиз. Каждая загрузка распаковывается в отдельный каталог `Documents\zapret\releases`; пользовательские списки и флаги переносятся из текущей сборки. Для переключения установленной службы после загрузки нажмите «Применить». Старые каталоги сохраняются. Эта кнопка обновляет сборку Flowseal, а не сам GUI.

«Редактор» открывает UTF-8 исходник выбранной стратегии. Сохранение проверяет параметры winws, обнаруживает сторонние изменения и создаёт соседний файл `.bak`. Изменения вступают в силу после применения стратегии.

«Тест» рядом со стратегией запускает штатный тестовый скрипт только для выбранного файла; тип проверки выбирается в отдельном окне. Скрипт требует отсутствия службы zapret, временно изменяет IPSet и запускает winws. GUI не удаляет службу автоматически. При несовместимой версии штатного теста отображается ошибка. Вывод внешних инструментов остаётся на языке Flowseal.

Тема переключается кнопкой луны/солнца в шапке и сохраняется локально. Значок приложения: `frontend/favicon.svg`, Windows ICO: `build/windows/icon.ico`. Для пересоздания ICO выполните `python scripts/make_icon.py` (без сторонних библиотек). Сборка Windows-ресурса в `build.ps1` требует `windres` из MinGW в PATH; ресурс включает иконку окна и EXE.

Вкладка «Списки» содержит текстовые файлы из папки `lists`, пояснения назначения и встроенный редактор UTF-8 (до 8 МБ). Сохранение создаёт соседний `.bak`, проверяет сторонние изменения и смену папки сборки. При смене списка предлагается отменить несохранённые правки; переход между вкладками сохраняет черновик. После редактирования перезапустите службу. Обновление сборки сохраняет пользовательские списки `*-user.txt`; штатные списки берутся из нового релиза.

### Переносимый EXE

Все HTML/CSS/JS и значки интерфейса встроены в EXE. Папка `frontend` для запуска не нужна; рабочая папка процесса не определяет расположение Flowseal. В шапке отображается версия GUI. Для проверки запуска интерфейса отдельно: `node scripts/check_frontend.cjs` (также запускается сборкой, если установлен Node.js).

Список релизов кешируется на 15 минут. При недоступном GitHub API GUI читает публичную страницу официальных релизов; токен GitHub для этого не требуется. После повышения прав исходное окно закрывается только после подтверждения готовности нового окна. Пользовательский и повышенный процессы используют раздельные профили WebView2.
